# Crypto Trading Reinforcement Learning Framework

This repository focuses on applying Reinforcement Learning (RL) techniques to model rational and strategic trading behavior in cryptocurrency markets. The project studies how RL agents respond to varying market conditions and tests the macroscopic impacts generated by distinct strategic trader profiles.

## Project Structure

The initial Jupyter notebooks have been professionally refactored into a scalable and completely modular Python codebase under the `src/` directory.

```text
.
├── src/
│   ├── data/
│   │   ├── features.py     # Generates customized technical/macro features
│   │   └── preprocess.py   # Data splitting, standard-scaling, and pipeline processing
│   ├── env/
│   │   └── crypto_env.py   # Gym Multi-Trader Framework (handles disparate reward mechanics)
│   ├── agents/
│   │   ├── dqn.py          # Value-Based Deep Q-Network Agent
│   │   └── reinforce.py    # Policy Gradient (REINFORCE) Agent with Baseline
│   ├── evaluation/
│   │   ├── shapley.py      # Feature attribution and SHAP/Permutation logic
│   │   └── plotting.py     # Macro regulator crisis plotting
│   └── main.py             # End-to-end execution pipeline
├── processed/              # (Generated) Cleaned Train/Val/Test CSV datasets
├── results/                # (Generated) Evaluation logs, summaries, and plots
├── methodology_report.md   # Detailed 2-3 page methodology report on findings
└── README.md
```

## How to Run

To run the complete evaluation for a specific cryptocurrency token (e.g. `AAVE`):

```bash
python -m src.main --sym AAVE --trader_types rational manipulator retail --episodes 150 --dqn_steps 150000
```

_(This commands trains all models for all three trader-types, runs the SHAP feature-importance analysis on each, and generates the resulting market crisis plots in the `results/` folder.)_

## Project Phases & Progress

### ✅ Phase 1: Foundation

- **Objective:** Establish the data universe and preliminary environment.
- **Achievements:**
  - Selected primary cryptocurrencies (e.g., AAVE, SUI, ETC) and retrieved high-fidelity hourly metrics (`Volume`, `High`, `Low`, `Close`, `Open`).
  - Integrated external macroeconomic predictors including S&P 500 (`ES=F`) and Gold (`GC=F`) futures to understand broader cross-asset correlations.

### ✅ Phase 2: Rational Investor Modeling

- **Objective:** Utilize foundational RL algorithms to model how a single rational investor behaves during steady-state, rapid climbs, and crash regimes.
- **Achievements:**
  - Designed the primary Gymnasium environment bounding actions to `Buy`, `Hold`, and `Sell`.
  - Implemented Temporal Difference (TD Q-Learning) alongside a Deep Q-Network (DQN) to optimize risk-adjusted returns (Sharpe ratio) over backtest data.
  - Explored stress-based correlations to understand liquidity evaporation during rapid declines.

### 🚀 Phase 3: Strategic Ecosystems & Explainable AI (Current Phase)

- **Objective:** Transition from studying a single rational agent to studying the holistic systemic impact of opposing strategic entities. Introduce advanced policy algorithms.
- **Achievements:**
  - **Refactoring:** Converted monolithic notebook code into structured `src/` modules for better lifecycle execution.
  - **Algorithm Upgrade:** Implemented **Policy Gradient (REINFORCE)** with an actor-critic baseline to stabilize volatility learning curves natively, comparing its stability directly against Phase 2's DQN.
  - **Trader Archetypes:** Adapted the environment rewards to autonomously train 3 conflicting trading styles:
    1. _Rational Arbitrageurs_: Seeking true Sharpe-maximized ROI.
    2. _Manipulators_: Prioritizing extreme turnover and wash-trading incentives.
    3. _Retail Herd_: Heavily penalized for straying from prevailing 24-hour momentum forces.
  - **Explainability (SHAP)**: Calculated isolated Shapley values for each trader archetype, mathematically mapping unique learned behaviors back to objective indicators.
  - **Regulatory Diagnostics:** Charted hypothetical crisis-frequency models based on aggregate populations.

### ⏳ Future Phases

- **Agent Convergence/Multi-Agent RL**: Pitting the resulting models live against one another in a shared limit order-book, testing whether manipulator strategies break down liquidity constraints for retail traders natively.
